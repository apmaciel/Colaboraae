# ColaboraAe

O **ColaboraAe** é uma plataforma mobile de gestão de tarefas colaborativas projetada para centralizar o gerenciamento de atividades, prazos e responsabilidades de equipes.

## 🚀 Sobre o Projeto
O ColaboraAe resolve o desafio da desorganização em equipes, oferecendo uma solução simples para acompanhar tarefas. O sistema conta com dois perfis de acesso:
*   **Administrador:** Gerencia tarefas e membros da equipe.
*   **Membro:** Acompanha e executa suas tarefas atribuídas.

## 🛠️ Tecnologias
O desenvolvimento do projeto utiliza um ecossistema focado em eficiência e agilidade:
*   **Interface:** Kotlin (Interface nativa) e Figma (Prototipação).
*   **Backend & Autenticação:** Firebase.
*   **Desenvolvimento:** Android Studio.
*   **Documentação & Modelagem:** Google Docs e Draw.io.

## 📋 Funcionalidades Principais
*   **Autenticação:** Login, cadastro e recuperação de senha.
*   **Gestão de Tarefas:** Criação, atribuição, edição e exclusão de tarefas.
*   **Colaboração:** Comentários, histórico de alterações e notificações de status.
*   **Gestão de Equipe:** Cadastro e exclusão de membros pela visão do administrador.
